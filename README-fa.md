# پیانوی سفارشی: پروژه اندروید

این پروژه همان صفحه پیانو را داخل یک WebView اندروید می‌گذارد و یک APK نصب‌شدنی می‌دهد.
فایل صفحه: `app/src/main/assets/index.html`

## روش ۱: ساخت APK در GitHub (بدون نصب چیزی روی رایانه)
1. در GitHub یک مخزن (repository) خالی بساز.
2. همه محتویات این پوشه را در ریشه مخزن آپلود کن. پوشه `.github` هم باید باشد.
3. برو به تب Actions، گردش‌کار «Build APK» را باز کن و Run workflow را بزن.
4. بعد از چند دقیقه، در پایین صفحه اجرا، فایل `piano-apk` را دانلود و از حالت ZIP خارج کن. داخلش `app-debug.apk` است.
5. فایل را روی گوشی بریز و نصب کن (اجازه «نصب از منبع ناشناس» لازم است).

## روش ۲: ساخت با Android Studio
1. Android Studio را نصب کن و File > Open را روی همین پوشه بزن.
2. صبر کن Gradle Sync تمام شود (اولین بار چند ده مگابایت دانلود می‌کند).
3. از منوی Build > Build Bundle(s) / APK(s) > Build APK(s) را بزن.
4. فایل خروجی: `app/build/outputs/apk/debug/app-debug.apk`

## نکته‌ها
- جهت صفحه پیش‌فرض افقی است. برای عمودی هم، در `AndroidManifest.xml` مقدار `sensorLandscape` را به `sensor` تغییر بده.
- فونت‌ها از Google Fonts بارگذاری می‌شوند. بدون اینترنت، فونت پیش‌فرض گوشی استفاده می‌شود و عملکرد برنامه تغییری نمی‌کند.
- این APK با کلید دیباگ امضا می‌شود و برای نصب شخصی کافی است. برای انتشار در مارکت‌ها باید با کلید خودت امضا کنی (Build > Generate Signed Bundle / APK).
- صداها و تنظیمات داخل خود برنامه روی گوشی ذخیره می‌شوند.
